A square bordered container on `surface`, used for decisions, notes, paper entries and the contact form.

Render it as a `<div>`, `<article>`, `<form>` or `<a>` with class `card`. The consumer provides the content and, when it is a link, the `href`. Use `card-dashed` for an empty state or a "coming soon" slot.

- Put an `h4` title and `text-muted` or `text-body` copy inside; add a `label` above when it helps.
- Stack cards with `space-5` between them and pad with `space-6`.
- Do not add shadows or rounded corners, and do not nest cards.
