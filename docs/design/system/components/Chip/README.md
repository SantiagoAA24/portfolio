A small bordered mono tag for technologies, categories and filters.

Render it as `<span class="chip">` for a static tag, or as an `<a>` with `chip` for a filter link. The consumer provides the text. The selected filter takes `chip-active`.

- Use it for stack lists (`React`, `FastAPI`) and notes filters (`All`, `AI`).
- Keep text short, one or two words.
- Do not use chips for sentences or for the primary action; that is a Button.
