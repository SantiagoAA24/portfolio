The uppercase mono caption that sits above a heading, a number or a group of rows.

Render it as a `<div>` or `<span>` with class `label`; add `label-accent` for section labels. The consumer provides short uppercase-friendly text, often numbered: `01 — SELECTED WORK`, `ON THIS PAGE`.

- Use `label-accent` for the label above a section title and `label` for captions and table headers.
- Keep it to one line.
- Do not use it for body text or for anything the reader must act on.
