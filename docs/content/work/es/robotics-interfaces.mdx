## Qué construí

1. Interfaces web de control que integran brazos robóticos y modelos de visión por computadora
2. Apps de escritorio multiplataforma con Electron para Linux, macOS y Windows
3. Frontends de dos proyectos reconstruidos a partir de diseños en Figma
4. Conexiones a servicios backend por REST y protocolos en tiempo real (WebSockets, MQTT)
5. Un esquema de base de datos rediseñado que escala entre proyectos, y APIs REST FastAPI sobre una arquitectura híbrida modular y hexagonal
6. Soporte a una herramienta interna que usa OCR y web scraping para procesar documentos automáticamente
